# Forge Freedom Homepage

The main homepage for forge-freedom.com - a personal portfolio and project showcase.

## Structure

```
homepage/
├── index.html          # Main homepage
├── css/
│   └── style.css      # Styles
├── js/
│   └── main.js        # JavaScript functionality
├── assets/
│   └── images/        # Images and media
└── README.md
```

## Development

This is a static website built with vanilla HTML, CSS, and JavaScript.

To develop locally, simply open `index.html` in a browser or use a local server:

```bash
python3 -m http.server 8000
```

## Deployment

The site is served via nginx on the production server at forge-freedom.com.
